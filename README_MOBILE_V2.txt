TokoFlow Mobile PWA V2
=======================
Perbaikan:
- Layout kasir otomatis 1 kolom di HP
- Sidebar mobile tidak lagi menutupi isi secara permanen
- Menu mobile memakai overlay dan bisa ditutup lewat link/Esc
- Header, tombol, input, produk, keranjang, dan tabel lebih adaptif
- Desktop tetap memakai layout dua kolom
- Tidak mengubah PHP/MySQL inti

Instalasi:
1. Ekstrak folder TokoFlow ke C:\xampp\htdocs\TokoFlow
2. Jalankan Apache dan MySQL di XAMPP
3. Buka http://localhost/TokoFlow/ di laptop
4. Dari HP pada jaringan yang sama buka http://IP-LAPTOP/TokoFlow/
