TokoFlow V22 - ALL FEATURES MODERN UI
====================================

This version keeps the real PHP + MySQL application logic from V21 and applies a
unified modern visual system across the entire application, not only Dashboard.

Updated visual system covers:
- Login / authentication
- Dashboard
- Kasir / POS
- Keranjang + payment UI
- Receipt / print view
- Riwayat transaksi
- Produk
- Kategori
- Stok
- Pembelian
- Supplier
- Pelanggan / CRM
- Pengeluaran
- Laporan + advanced analytics
- Premium / upgrade pages
- Promo / retur / piutang / shift / staff / backup modules
- Pengaturan + theme controls
- Audit Log
- Developer test page

The redesign is CSS/UI only where possible, so the existing PHP/MySQL actions,
forms, routes, authentication, transactions and database remain the functional
parts of the app.

Install:
1. Extract this TokoFlow folder into C:\xampp\htdocs\TokoFlow
2. Start Apache + MySQL in XAMPP
3. Open http://localhost/TokoFlow/
4. Use the existing database/config flow.
