TokoFlow V24
============

This version fixes the duplicated Dashboard header from V23 and applies a unified
modern UI layer across the existing PHP/MySQL application instead of replacing it
with a static mockup.

The original application routes and backend are retained. UI styling is applied
globally to POS, products, stock, purchases, suppliers, customers, reports,
promos, returns, receivables, shifts, staff, backup, settings, premium and audit
log pages. Dashboard content is loaded from the real database.

Install:
C:\xampp\htdocs\TokoFlow\

Run Apache + MySQL, then:
http://localhost/TokoFlow/

Important:
V24 removes the dashboard-local duplicate title/header. The only Dashboard title
is the global page header generated by headerUI(). Dark mode remains available if
selected in Settings; the UI is coherent in both modes.
