TokoFlow V25 — MODERN UI REFINEMENT

Perubahan visual:
- Kasir/POS diperbarui dengan layout checkout yang lebih modern.
- Area produk memiliki header, pencarian yang lebih jelas, kartu produk interaktif, dan indikator tambah.
- Keranjang/checkout dibuat lebih terstruktur dan mudah dipindai.
- Dashboard, Produk, Stok, Pembelian, Supplier, Pelanggan, Laporan, Promo, Retur, Piutang, Shift, Tim, Backup, Pengaturan, dan halaman premium memakai sistem visual yang konsisten.
- Audit Log diperbarui menjadi tabel modern dengan hierarchy, spacing, badge, dan dark mode yang konsisten.
- Dark mode dibuat lebih rapi dengan slate surface, border halus, dan accent mengikuti warna tema.
- Light mode juga dirapikan agar tidak terlihat polos.
- Responsive untuk desktop, tablet, dan mobile.

Fungsi PHP, database, transaksi, pembayaran, struk, login, paket premium, dan audit tetap menggunakan alur yang sudah ada. Perubahan ini fokus pada UI/UX.
